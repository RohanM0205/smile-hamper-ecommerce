# 🎁 Smile Hamper - Full Stack E-commerce Application

## 📌 Overview
Smile Hamper is a full-stack e-commerce web application where users can:
- Browse premium hampers
- Build custom hampers
- Add to cart
- Place orders
- Make payments via Razorpay
- Track order confirmation

## 🛠 Tech Stack
Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- Supabase
- PostgreSQL
- Row Level Security (RLS)

Payment Integration:
- Razorpay

## 🚀 Features
- User authentication
- Dynamic cart system
- Razorpay payment integration
- Order creation API
- Supabase RLS security
- Responsive premium UI
- Admin product management

## 📂 Project Structure
- /app
- /components
- /lib
- /api
- /public

## 🔐 Security
- Environment variables protected
- Supabase Row-Level Security implemented
- Payment verification server-side
